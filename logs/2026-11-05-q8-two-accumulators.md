# Q8_0 双累加器实验（2026-11-05）

## 方法

在 llama.cpp 的 `ggml_vec_dot_q8_0_q8_0` AVX2 分支中，用两个独立累加器处理相邻量化块；另行处理奇数个块的尾块。改动和新增测试保存在 [实验补丁](patches/2026-11-05-q8-two-accumulators.patch)。优化版构建显示提交 `170ae83c`，该提交号不包含尚未提交的实验补丁，因此复现时须同时使用补丁。

原版使用 `build-ascii`，优化版使用独立的 `build-q8-opt`。两者使用同一 Qwen3-0.6B Q8_0 模型、8 个 CPU 线程、`-ngl 0 -b 2048 -ub 512`。每项按原版与优化版交替运行 5 轮，每轮各执行一次。

## 正确性

`test-quantize-fns` 总计 0 项失败。新增的 32 和 96 元素 Q8_0 点积测试均通过，误差均为 0.000122，低于测试上限 0.02。

## 性能结果

| 负载 | 原版中位数（token/s） | 优化版中位数（token/s） | 变化 |
| --- | ---: | ---: | ---: |
| 生成 256 token（`-p 0 -n 256`） | 56.762 | 56.663 | -0.17% |
| 处理 512 token（`-p 512 -n 0`） | 374.472 | 377.227 | +0.74% |

原始 JSON 和逐轮 CSV 分别见 [生成实验](raw-q8-opt/20261105-172633/)与[提示处理实验](raw-q8-opt/pp512-20261105-173515/)。生成实验第 4 轮优化版比同轮原版慢 8.32%；提示处理实验第 3 轮慢 8.33%。其余配对差异较小。未确定这两次波动的原因。

## 结论

双累加器改动通过了现有正确性测试，但没有表现出可靠的模型级速度收益。本轮不采用该源码改动；测试后已恢复核心仓库中的实验修改。后续以分阶段线程配置作为优化重点。
